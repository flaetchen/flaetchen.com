# Content Architecture

## Principle
Content is independent from presentation.

## Projects
Recommended fields:
- slug
- title
- client
- year
- industry
- short intro
- full intro
- services
- technologies
- challenge
- approach
- solution
- outcome
- hero media
- supporting media
- credits
- SEO metadata

## Services
Recommended:
- slug
- title
- positioning
- description
- process
- deliverables
- related projects
- technologies
- FAQs where useful
- SEO metadata

## Agency
Possible areas:
- positioning
- philosophy
- quality standard
- approach
- founder
- process
- collaboration model
- selected clients
- contact

## Homepage
The homepage should curate, not dump.

## Case Studies
Use shared content data and reusable editorial modules, while allowing project-specific composition.
