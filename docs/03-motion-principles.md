# flaetchen Motion Principles

## Goal
Motion should make the site feel authored, continuous and premium.

## Motion Hierarchy
Micro motion:
- links
- buttons
- nav
- focus
- hover

Reveal motion:
- important type
- project media
- section entrances

Scene motion:
- project handoffs
- full-screen changes
- dark/light transitions
- media transformations

## Rules
- no fade-up everywhere
- no bounce
- no excessive parallax
- no random transforms
- no constant movement
- no scroll-jacking
- no animation-only information

## Preferred Behaviors
- clip/mask reveals
- media scale within a fixed crop
- persistent media
- large typography moving independently from imagery
- staged scene handoffs
- project teaser → case continuity
- dark/light transitions
- subtle logo contrast adaptation

## Mobile
Do not force desktop choreography onto mobile.

## Reduced Motion
Content remains immediately visible and usable without large spatial motion or long scrub sequences.
