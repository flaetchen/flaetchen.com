# Implementation Roadmap

## Phase 1 — Reference Analysis
Analyse Preymaker and Ownitt. No implementation.

## Phase 2 — Creative Direction Approval
Choose homepage narrative, hero direction, project presentation, founder treatment, service storytelling, navigation behavior and motion philosophy.

## Phase 3 — Technical Foundation
Create `/web` with Next.js, TypeScript, App Router, Outfit, tokens, metadata foundation and reduced-motion support.

## Phase 4 — First Visual Prototype
Build only:
1. Hero
2. first project handoff
3. one calm content scene

Validate quality before continuing.

## Phase 5 — Project System
Develop project model, selected-work presentation, case-study foundation and transitions.

## Phase 6 — Services
Develop service storytelling without generic cards.

## Phase 7 — Founder / Agency
Develop founder and agency presence.

## Phase 8 — Fullscreen Navigation
Finalize motion, hierarchy, states, accessibility and responsive behavior.

## Phase 9 — Remaining Pages
Projects, services, agency, contact and legal pages.

## Phase 10 — SEO / GEO / Accessibility
Audit metadata, headings, schema, internal links, keyboard, focus, reduced motion and contrast.

## Phase 11 — Performance
Measure and optimize LCP, CLS, INP, JS, media weight, animation cost and mobile Safari behavior.

## Phase 12 — Final Creative Review
Reject anything that looks templated, generic, overloaded or animated without purpose.
