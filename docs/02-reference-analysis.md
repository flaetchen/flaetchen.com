# Reference Analysis Framework

Primary references:
- https://preymaker.com/
- https://ownitt.fr/

Analyse each under:
1. first impression
2. visual hierarchy
3. typography
4. media
5. motion
6. pacing
7. navigation
8. projects
9. services/agency content
10. mobile
11. transferable principles
12. non-transferable elements

Do not summarize with vague words like "modern", "clean" or "dynamic". Describe actual mechanics.
