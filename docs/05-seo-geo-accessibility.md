# SEO, GEO & Accessibility

## Principle
The animated experience sits on top of a strong semantic content layer.

All meaningful content must be present in HTML.

## Required
- semantic HTML
- logical heading hierarchy
- crawlable navigation and links
- per-route metadata
- canonical URLs
- sitemap
- robots
- Open Graph
- project/service metadata
- meaningful alt text
- structured data where useful

## GEO
Creative slogans are not enough. Important pages need clear factual statements about who flaetchen is, what it does, how it works and which projects prove those capabilities.

## Accessibility
Required:
- keyboard navigation
- focus-visible
- semantic controls
- reduced motion
- accessible contrast
- no invisible tab targets
- no animation-only information
